Provider settings

Set up or rotate your OpenAI key. Keys are kept in private server storage and are never returned to this page. Leave the key empty to keep the saved key.

Saving checks access to the configured model IDs without generating a response. Model access does not guarantee billing, reasoning-option or tool compatibility. Use model IDs and reasoning options supported by your account.

Limits apply to all OpenAI requests, including background research. Token accounting includes conservative reservations for failed or interrupted calls; it is not a dollar billing cap. Hosted search may add charges. Keep account spending controls enabled at your provider.

Saved changes take effect after you manually restart KlipperAI. Rotation does not revoke the previous key at OpenAI. After restarting and checking the new key, revoke the old key in your provider account.
